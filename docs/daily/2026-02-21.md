## Session Focus: Phase 6 POC Results & v8 Training Launch

### Frame Skip Replay POC — Completed

Implemented the three TODO sections in `scripts/poc_frame_skip_replay.py`:
- `parse_episode_actions()` — regex extraction of frame/action from smbdataset PNG filenames
- Imports for gym-super-mario-bros, JoypadSpace, SIMPLE_MOVEMENT
- `replay_episode()` — environment creation, action replay loop, result tracking

**POC Results (v3 env, frameskip=1):**
- Full-speed replay only reached x=839-899 (25% of level) despite using winning episode data
- Subsampled (skip=4) dropped to ~35% of full-speed distance
- Root cause: action timing mismatch between 60fps recorded data and env physics, plus lossy NES→SIMPLE_MOVEMENT action mapping
- **Conclusion: Imitation learning not worth the investment.** Raw action sequences are too brittle — a model trained on noisy/broken trajectories would inherit those problems.

### Major Discovery: v7 Was Already Beating 1-1

Early v8 training with fixed callbacks revealed:

- The "2700px ceiling" from v7 analysis was a **metrics bug**, not a training plateau
- Completed episodes show lower raw distance (1840 avg) because Mario enters 1-2 and the distance tracking changes

### Key Learnings

1. **Always validate metrics before concluding there's a plateau.** The v7 "ceiling" was broken callbacks, not a real training limitation.
2. **Imitation learning from recorded demos has fundamental timing/mapping challenges** that make it impractical for this use case.
3. **Fine-tuning existing weights** is far more efficient than building a new pipeline (imitation learning) when you already have a working model.
