## What I Accomplished

- Created `notebooks/06_ppo_v8_analysis.ipynb` — full v7 vs v8 comparison
- **Found the root cause of the plateau**: `RewardShapingWrapper` has no guard on `x_delta` at level transitions. When Mario enters 1-2, `info["x_pos"]` resets to ~0, producing `x_delta = -3154` and a ~-315 reward penalty. The agent learns to AVOID beating the level.
- The base game env has a guard (`if abs(delta) > 5: return 0`) but the wrapper bypasses it by reading `info["x_pos"]` directly
- v8 stats: 9.2% completion rate, max x_pos 5098 (one episode got ~2K into level 2), completion rate actually drops over training confirming the agent is learning to avoid the flagpole
- Ran eval script successfully — agent plays well but avoids finishing

## What I Learned

- The base `smb_env._x_reward` already clamps large deltas to 0 — the wrapper's custom `x_delta` calculation bypasses this safety
- Completion rate declining over training is a clear signal of reward signal corruption — the agent is being anti-trained on the exact behavior we want
- `uv` and Poetry projects don't mix — uv hook intercepting python commands in Poetry projects nukes the venv
